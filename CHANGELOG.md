# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-07-18

### Added

- Bazzite-only native Sunshine installer with staged RPM layering.
- Existing Flatpak identity and pairing migration.
- Connected-display DRM adapter detection with manual overrides.
- Pre-login KMS system service for Plasma Login Manager.
- Service-scoped input, video, render, and capability access.
- Tray-disabled session survival across logout and login.
- Boot-time PipeWire, PipeWire-Pulse, and WirePlumber startup.
- Virtual audio sink readiness wait for audio in the first cold-boot stream.
- Verification and rollback scripts.
- GPL-3.0-only licensing and public installation documentation.
